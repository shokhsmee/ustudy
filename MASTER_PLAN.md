# Odoo Education: Глобальная Архитектура и План Разработки
## 1. Фундаментальные Принципы
- Товарная матрица: Используем ТОЛЬКО `product.template`.
- Soft Constraints: Гибкая логика лимитов с правами переопределения.
- Дизайн (Swiss-style): Максимальный минимализм, слово "Обзор" вместо "Sharhi".
## 2. Архитектурные Блоки
- Блок A: Академическое Ядро (Модели групп, студентов, плавающее расписание).
- Блок B: Непробиваемое Финансовое Ядро (account.move, SQL locks).
- Блок C: Экосистема (FaceID, Telegram-бот, интеграция платежек).
- Блок D: Геймификация (XP, магазин наград).
